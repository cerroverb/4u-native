Build the game code on this PC (the game folder screen, or Settings, System, Game code): the tools it downloads

The first time it runs, the builder downloads these tools from their official sources, checks each one against its
SHA-256 and keeps them in the builder folder beside MH4U.exe. They are not in the MH4U-PC zip, and none of them is game
data. The builder runs them with zigcc.exe, a small program of MH4U for PC that hands Zig's C compiler its options.
